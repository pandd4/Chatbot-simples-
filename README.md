# **Chatbot Simples - Azul e Branco**  

Um chatbot simples desenvolvido com **HTML, CSS e JavaScript**, capaz de responder perguntas básicas e buscar informações sobre **clima, horário e signos** no Google.  

## 📌 **Funcionalidades**
✅ Interface de chat estilizada em **azul e branco**.  
✅ Respostas automáticas para perguntas comuns.  
✅ **Busca no Google** para obter informações sobre **clima, hora e signos**.  
✅ **Rolagem automática** para a última mensagem.  

## 📂 **Estrutura do Projeto**
```
📁 chatbot
│── 📄 index.html       # Estrutura do chatbot
│── 🎨 style.css        # Estilo da interface
│── ⚡ script.js        # Lógica do chatbot
│── 📜 README.md       # Documentação do projeto
```

## 🚀 **Como Executar**
1. Baixe ou clone este repositório.  
2. Abra o arquivo `index.html` no navegador.  
3. Comece a interagir com o chatbot!  

## 🛠 **Tecnologias Utilizadas**
- **HTML5** → Estrutura da página  
- **CSS3** → Estilização do chat  
- **JavaScript (JS)** → Lógica do chatbot  

## 🎯 **Como Usar**
Digite sua mensagem na caixa de entrada e pressione **"Enviar"**. O chatbot responderá automaticamente com base nas seguintes regras:  

📍 **Respostas diretas**  
- "Oi" → "Oi! Como posso ajudar?"  
- "Qual seu nome?" → "Sou um chatbot simples!"  
- "Obrigado" → "De nada! 😊"  
- "Tchau" → "Até logo! Tenha um bom dia!"
